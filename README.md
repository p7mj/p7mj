# P7MJ

This is **P7MJ**, a private, casual developer. I like to make various utilities that serve one or more purposes in the random tasks that I encounter.

I am a big fan of Linux and personally run 4 operating systems, 3 of them Linux, on my laptop. My favorite one is Debian KDE, although my custom XFCE Arch is a contender.

I mainly use wholeworldcoding's [Forgejo](https://git.wholeworldcoding.com/P7MJ) instance for my projects. Some of the projects here link back to the Forgejo instance.

Things on work on include [Cube A](https://git.wholeworldcoding.com/wholeworldcoding/WrldBox/src/branch/cube_game), a branch of WrldBox that prioritizes a strong framework and moddability; [Chatter](https://chatter.wholeworldcoding.com/), a chat app by my organization; and ClickedIn (private repo), an alternative to Saturn, that hopefully one day gets deployed across schools in the US.

### Finished Projects 

[BUGPy-mOS](https://github.com/p7mj/bugpy-mos): The OS concept, but in Python. It has its own package manager, shell, text editor, and supports scripting and further development from *within* the OS.

[P7MC](https://git.wholeworldcoding.com/p7mj/P7MC): a TUI vanilla Minecraft launcher I made as a small side project, now available on GitHub.

[Interceptor-APS](https://git.wholeworldcoding.com/p7mj/Interceptor-APS): a program that automatically detects file changes and switches your screen to a predetermined window.

[in-the-air](https://git.wholeworldcoding.com/p7mj/in-the-air): Prototype discord mood analyzer that takes exported chat logs from the browser plugin DiscordKit and analyzes the chat mood.

[Command-Line-Radio](https://git.wholeworldcoding.com/p7mj/Command-Line-Radio): Experimental chat app that connects to an ip and allows chatting over the local network.

[Sierra-Security](https://git.wholeworldcoding.com/p7mj/Sierra-Security): a Time-based One-Time Password (totp) verification module with plans to be integrated into my systems.

[Chatter-Desktop](https://git.wholeworldcoding.com/p7mj/chatter-desktop): Chatter desktop binaries for Windows.

Social Bathroom Credit: A program to track social credit... but for bathrooms?!! (Not posting)
